# M3 Verification Log

## Scope

Web preview for the exam loop: create session, start timer, answer a question, save, request AI hint, submit idempotently and view report.

## Current Status

Partially verified locally on 2026-06-29.

This is a development preview backed by in-memory API state and the shared MVP fixture. It does not prove durable Supabase persistence yet.

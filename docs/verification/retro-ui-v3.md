## 开发启动

```sh
pnpm install --frozen-lockfile
pnpm test:retro-ui
pnpm verify
pnpm dev
```

依次检查 `/`、`/exam`、实际会话、实际报告、错题页及分享页。
手动补测：切换年份后旧候选不可开考；慢响应不覆盖新选择；目录失败可重试；开始接口失败不跳转；阅读开关刷新恢复；浏览器禁用存储；手机软键盘；不同得分及待复核报告。

样式仅引用系统字体，不打包字体文件；材质由CSS生成，不依赖外部图片CDN。
上线前仍需真机验证WXSS、图片海报生成器的配色以及现有服务端权限边界。

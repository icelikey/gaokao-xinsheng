## Evidence

- Miniprogram source exists at `apps/miniprogram`.
- It includes five entry pages:
  - `pages/index/index`
  - `pages/exam/index`
  - `pages/report/index`
  - `pages/mistakes/index`
  - `pages/share/index`
- The miniprogram API client exists at `apps/miniprogram/utils/api.js`.
- The client calls service-side APIs only:
  - `GET /api/health`
  - `GET /api/v1/catalog/years`
  - `GET /api/v1/catalog/regions`
  - `POST /api/v1/catalog/match`
  - `GET /api/v1/papers/:paperId`
  - `POST /api/v1/exam-sessions`
  - `POST /api/v1/exam-sessions/:sessionId/start`
  - `PUT /api/v1/exam-sessions/:sessionId/answers/:questionId`
  - `POST /api/v1/exam-sessions/:sessionId/ai-help`
  - `POST /api/v1/exam-sessions/:sessionId/submit`
  - `GET /api/v1/reports/:reportId`
  - `POST /api/v1/reports/:reportId/share-cards`
  - `GET /api/v1/share/:token`
- A user-facing public paper API was added:
  - `GET /api/v1/papers/:paperId`
  - It returns the MVP paper without `answer` or `rubric`.
- Static verifier exists:
  - `scripts/miniprogram-contract-check.ts`
  - root script: `pnpm test:miniprogram-contract`
  - root `pnpm verify` now includes the miniprogram contract check.
- The miniprogram entry page matches candidate papers before creating an exam session, and the exam page loads the public paper from the created session's `paperId`.
- The report page can navigate into `pages/mistakes/index`, which reads the report API and filters missed-score or review-required questions.

## Security Boundary

The static check asserts:

- required miniprogram files exist
- `app.json` registers the five expected pages
- miniprogram client uses `/api/v1/papers/`
- miniprogram client uses `/api/v1/catalog/years`, `/api/v1/catalog/regions` and `/api/v1/catalog/match`
- miniprogram client does not use `/api/catalog/`
- miniprogram client uses exam, report and public share APIs
- miniprogram global state and env do not pin a fixed `paperId`
- exam page loads paper details from `session.paperId`
- report page exposes a `错题回看` action and passes `reportId` to `pages/mistakes/index`
- mistakes page reads `api.getReport`, filters `score < maxScore || requiresReview`, and renders filtered questions
- miniprogram source does not include secret-like patterns such as service role key, model key or AppSecret
- public paper payload contains 30 questions and does not include `"answer"` or `"rubric"`

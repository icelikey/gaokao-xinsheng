# V6：2000—2025语数英档案

## 已实现

- 限定预算、来源域名、robots与文件签名的采集器；固定版本社区数学汇编保留提供者身份，不冒充官方。
- `/admin/papers/archive` 26×3覆盖视图，本机读取清单，按年/科/状态筛选，保留失败和未知年份；不上传材料、不启用考试或RAG。
- 20MB/20000条导入上限，校验URL、SHA256、文件路径和状态，禁止把下载成功当成内容审核成功。
- 第2批补采仅依据实际已发布分页参数和第1批缺失数学路径；旧新浪页面的发布年份不自动当作考试年份。
- 原件加密后才上传临时Actions artifact，私钥不进入GitHub。两批均为本次明确限定事件的一次执行，无定时采集。
- 可选原生PDF文本提取脚本（需要在私有内容环境安装PyMuPDF），不OCR、不改写、不生成答案。输出unclassified_source_page且enabled=false，公式/多栏错序仍须审校。
- 增补内容目录与私钥的.gitignore保护。原件、转录和答案不进入公开Git目录。

## 实际第1批（2026-09-19）

下载与解密后检查到853条来源记录，466份社区数学PDF、224个来源网页缓存、110条获取失败、53条未执行。附件另有语文/英语PDF与Word、图片。这些数量不是独立历史原卷总数。首次批次触及350MB传输预算，109个失败由预算中止造成，不应标成永久404。

对838个被清单引用的唯一文件重新校验SHA256和字节数，无不一致；其中468个PDF可被解析，共1127页。原生文本提取得到1127页草稿，1071页非空、56页无文字。可解析或可提取不等于内容准确、完整或权利范围已逐项核定。

福建2012理科数学官方页面的7幅图片已全部取得，包括上一轮缺失的印刷页18；尚不据此宣布整套内容/评分独立审校完成。

第2批结果以其独立inventory与本次会话交付的合并清单为准；不预写未完成的下载数量。

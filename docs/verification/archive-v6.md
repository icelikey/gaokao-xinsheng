# V6：2000—2025语数英档案

## 本次实现

- 有预算的来源发现/采集，不登录、不绕过访问限制、不把来源条目冒充原卷。
- 26×3目录视图，Spring/普通场次、文理与卷名继续保留来源元信息，不自动替用户核定适用省份。
- 本机读取清单、按年/科/状态筛选、查看失败和来源、导出清单。新页面 `/admin/papers/archive` 不向服务器上传清单，不写入当前考试库。
- 导入边界限制20MB/20000条，校验年份、科目、来源URL、文件哈希与路径；禁止通过清单把ready/RAG状态置true。
- 无私人心理档案、疗效承诺、公开排名；用户可通过熟悉的题目和可解释批改重新回看过去。

## 验证

本地14项Python采集器单元测试、17项清单契约测试通过。新增真实Next构建+Chromium页面测试；最终远程结果以PR最新Actions为准。浏览器fixture完全原创，截图不是已核验真题覆盖的证据。

真实采集只在本次分支PR创建事件执行一次，原文件加密后进入临时artifact。新页面推送不应重新触发批量采集。采集结果要下载解密后检查每个文件真实SHA256，与内容校验分开。

## 不覆盖

没有宣称2000—2025所有地区版本收齐；未建立权威卷型分母、逐题转录、完整音频匹配、独立教研复核或生产发布。网络失败、字节成功但题目不完整、转载重复都需保留。没有改变现有评分、AI密钥、数据库或鉴权。

# 考场工作区 V4｜开发与验收记录

日期：2026-09-17。基于 main `de816d8a12a6f705e463a04663ead4cfc06b6097`。

## 实际改动

1. Web考场改为通过会话paperId读取公开题目API，不直接导入包含答案键和评分规则的完整mvpPaper。
2. 为现有14道合成选择题补齐选项文字，保持既有答案键；界面明确“流程演示样卷”和“预置辅导/估分”。没有导入或声称导入任何真实历年试卷。
3. 新增可测试工作区控制器：自动保存、串行同步所有待保存题、快速输入保护、保存失败阻止提示/交卷、幂等交卷、终态只读。
4. 同标签页sessionStorage保存草稿、未同步答案、标记与位置。本机/服务器冲突须确认，未处理冲突在反复刷新后仍保留；刷新服务器状态期间禁止并行写入；卸载后的迟到回包不覆盖新页面缓存。
5. 复古工作区包括答题卡筛选、草稿纸、按题提示、第四级确认、交卷检查、计时隐藏、暂离遮罩。暂离不暂停服务器计时，界面明确告知。
6. 草稿不发送给AI或评分；可由用户主动追加到正式答案。存储失败可导出JSON备份。恢复后答案输入框使用稳定的无障碍标签。

pnpm install --frozen-lockfile
pnpm test:exam-workspace
pnpm verify

初次提交5548aa7的GitHub标准CI通过（lint、typecheck、既有契约/黄金集、新增32项测试、Next build）。初次浏览器验收通过公开试题读取、四种宽度与跨题保存，在刷新后输入框标签定位处失败；本次修复标签，不移除相应测试。最终结果必须查看最新提交的Actions，不沿用旧提交的通过状态。

浏览器检查工作流：`.github/workflows/workspace-browser.yml`。Playwright 1.58.0，真实Next生产构建+本地memory fixture，无云端密钥、无hosted Supabase写入。截图、结果JSON、trace、服务器日志上传为7天Actions artifact。覆盖刷新恢复、草稿隐私、注入503失败、提示前版本、实际交卷、终态只读。

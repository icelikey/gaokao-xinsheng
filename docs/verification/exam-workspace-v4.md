# 考场工作区 V4｜开发与验收记录

日期：2026-09-17。基于 main `de816d8a12a6f705e463a04663ead4cfc06b6097`。

## 实际改动

1. Web 考场不再从客户端导入完整 `mvpPaper`。通过会话 `paperId` 读取公开题目 API，避免在答题包中直接导入答案键及评分规则。
2. 为现有14道选择题补齐选项文字，仅适用于仓库的合成样题 ID。界面始终明确“流程演示样卷”和“预置辅导/估分”。没有导入或声称导入任何真实历年试卷。
3. 新增独立可测试的考试工作区控制器：自动保存、串行同步所有待保存题、快速改答案保护、保存失败阻止提示/交卷、幂等交卷、终态只读。
4. 同标签页 sessionStorage 草稿与未同步答案恢复；本机/服务器冲突必须确认。存储失败可导出JSON备份。草稿不发送给AI或评分服务；追加到正式答案由用户主动操作。
5. 复古工作区：答题卡筛选、题目标记、正式答案、草稿纸、按题保留的四级提示、交卷确认、参考计时隐藏、暂离遮罩。暂离不暂停服务器计时，界面明确告知，不假装实现暂停接口。
6. 增加控制器/HTTP/内容边界自动化测试和可重复运行的真实Next路由浏览器检查。

## 验收命令

```sh
pnpm install --frozen-lockfile
pnpm test:exam-workspace
pnpm verify
```

浏览器检查在 `.github/workflows/workspace-browser.yml` 中独立运行。使用锁定的 Playwright 1.58.0 和本地 memory fixture，不读取云端密钥、不写入 hosted Supabase。运行截图、结果JSON、trace 和服务器日志作为短期 Actions artifact 保存。

## 本地已完成

`exam-workspace-check.ts` 经TypeScript转译后在Node内置测试执行器运行：32项通过。包含跨题保存、保存失败阻止提示/交卷、快速编辑、请求重试、幂等交卷、恢复冲突、过期/损坏缓存、私密草稿边界、计时、公开数据加载与HTTP错误/超时。

本地环境无法下载完整仓库依赖，故本地结果不等同于整个Next应用构建成功。完整lint、typecheck、既有契约测试、生产构建和浏览器结果必须以本提交对应的GitHub Actions为准。

# V5 真题来源整理：2012 福建理科数学

本轮接入的是 **source staging（来源整理与核验）**，不是直接发布一套已校准考试。保留 V4 的考试会话和现有演示卷；不将演示题替换成缺页/未审核内容。

## 已核定的来源与结构

- 官方发布页：https://www.eeafj.cn/systsj/20120608/2148.html
- 发布机构：福建省教育考试院；发布日期2012-06-08，不能用作考试日期。
- 发布页链接7幅扫描图，印刷页码14—20。本轮视觉读取6幅；印刷页18对应的 `1339161668061_sxlkda_3.jpg` 多次超时。
- 题面按1—21编号。第21题含三个各7分的可选模块，任选两题；超答按所做前两题评分，不是取最高两题。
- 结构化时分为23个可作答项目。全部项目简单求和157分，按三选二规则计算满分150分。
- 题目1—10为选择题，每题5分；11—15为填空，每题4分；16—19每题13分；20题14分；21题任选两项共14分。上述规则来自扫描件，不套用MVP的固定30题。
- 首张扫描上部是其他科目材料，最后一张下部开始文史类数学；不能整页当作理科考生题面。第三张还混有参考答案。

## 私有交付与公开代码

完整题干和答案的视觉转录首稿通过会话交付，不嵌入公开仓库。`docs/content/*.sources.json` 仅含来源网址、状态及结构摘要。原始图像/参考解答/授权文件请放 `private-content/` 或其他私有存储。

首稿包含23项题目，21项参考答案文本或摘要；18、19题参考解答未完整取得，整题答案标MISSING。未缺失的答案也只是首校，不代表官方逐步rubric或人工复核完成。未生成四级提示，未用推导结果补造来源。考试实际日期、时长没有由本批扫描确认，留空。

## 使用

1. 打开 Web `/admin/papers/intake`；题库页有“真题来源整理”入口。
2. 选择本轮交付的 `fj-2012-math-science.source.json`。文件只在浏览器中处理；没有上传、发布、持久化接口，刷新清空。
3. 检查原题号、子题、来源清单、选考总分和缺失项。
4. 可导出核验报告、无答案题面草稿、RAG整理草稿。RAG文档按题面/参考答案隔离且 `enabled=false`，不能直接送入辅导检索。
5. 在有网络的本机运行素材采集脚本。默认只展示计划：

```bash
python3 scripts/acquire-exam-source.py
python3 scripts/acquire-exam-source.py --download
```

下载失败会保留缺失状态并以非零退出；只对实际取得的字节生成SHA-256。原图下载成功仍不等于人工复核完成。本会话环境无法取得原图到本地，因此私有包没有伪装的原图或伪造的图片哈希。

## 和旧导入API的关系

旧 `PaperImportPayloadSchema` 限定QUICK_15且30—50题，原有评分和目录仍绑定演示卷。V5不靠补题凑数、不伪造rubric、不绕过这些约束。新的 `source-paper/1` 是真实来源的上游中间格式；未来增加正式运行时适配与受保护发布API后再提升为可开考数据。

不得将本地导出显示为“已上线”。不得向考生发送含答案的扫描整页。正式素材应先裁切分离题面与解答，并使用私有存储受控访问。
